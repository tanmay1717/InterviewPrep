Interview Prep Tracker Chrome · Edge · Brave · Arc
Download extension (.zip)
  1. Unzip the download.You'll get a folder called interview-prep-extension. Move it somewhere it can stay, like Documents - Chrome loads the extension from it.
  2. Open the extensions page.Paste this into the address bar: chrome://extensions (Edge: edge://extensions, Brave: brave://extensions.)
  3. Turn on Developer mode.It's the switch in the top-right corner of that page.
  4. Click “Load unpacked”.Choose the interview-prep-extension folder from step 1.
  5. Pin it and sign in.Click the puzzle-piece icon in the toolbar, pin Interview Prep, open it, and sign in on its Friends tab with this account.

Updating

Download again, replace the old folder with the new one, then click the reload icon ↻ on the extension's card in chrome://extensions. Your progress is safe - it's stored in your account.

Why “Developer mode”?

Extensions from outside the Chrome Web Store install this way. It's the same code this site runs - Chrome just shows a small reminder that it's loaded from a folder.

Gmail detection

Optional and off until it's set up for this site. Everything else - calendar, system design, friends and sync - works straight away.
